Student Management System (SMS) | Full-Stack Web Application

Enterprise Campus Management Platform with 3-tier Role-Based Access Control, attendance tracking with eligibility checks, fee invoicing ledger, and examination grading.

Project Overview & Architecture

The Student Management System (SMS) is an end-to-end Enterprise Campus Management Platform architected with Python, Django, Django REST Framework, and MySQL / PostgreSQL, deployed live in production on PythonAnywhere WSGI. Engineered to streamline institutional workflows, the platform enforces granular Role-Based Access Control (RBAC) across 3 distinct tiers: System Administrators, Faculty Members, and Students — providing customized dashboards, automated business rules, financial ledger tracking, and high-performance ORM queries.

Core Technical Highlights & Accomplishments
  • Enterprise Campus Platform & 3-Tier RBAC: Architected and deployed an end-to-end Enterprise Campus Management Platform supporting Role-Based Access Control (RBAC) across 3 distinct tiers: System Administrators, Faculty, and Students.
  • Modular Academic & Invoicing Endpoints: Engineered RESTful API endpoints and modular Django apps for Attendance Tracking, Fee Invoicing, Examination Timetables, Coursework Assignments, and Academic Grading (CGPA/GPA).
  • Interactive Data-Driven Student Dashboard: Implemented an interactive, data-driven Student Dashboard visualizing live metrics including attendance percentage (>75% eligibility check), outstanding fee balances, pending submissions, and exam countdowns.
  • Relational Schemas & Query Optimization: Designed relational database schemas utilizing Django ORM, optimizing complex multi-table queries (select_related, prefetch_related, Q objects, aggregation) to ensure low latency.
  • Financial Ledger & Invoice Engine: Built a Financial Ledger & Invoice Engine automating fee receipts, transaction logs, and partial/full payment state tracking.
  • Production Cloud Deployment & Pipelines: Deployed production application to cloud hosting via PythonAnywhere WSGI, utilizing Git for version control and migration pipelines. Live URL: https://vyankateshwarpund.pythonanywhere.com/login/.

Enterprise Portfolio & Analytics Platform

Full-stack analytics & portfolio platform powered by Django, Django REST Framework, MySQL, Docker CI/CD, PWA, and WhiteNoise static asset pipeline.

Project Overview & Architecture

The Enterprise Portfolio & Analytics Platform is a high-performance web system engineered with Python, Django, Django REST Framework (DRF), and MySQL. Designed to provide recruiter transparency and granular engagement insights, the system structures 36 relational tables and exposes 40+ REST API endpoints with database query optimizations. It incorporates custom Django middleware for real-time visitor IP tracking, session auditing, a dynamic recruiter analytics dashboard built with Chart.js, and containerized deployment with Docker and Render CI/CD pipelines.

Core Technical Highlights & Accomplishments
  • Full-Stack Backend Architecture (36 Tables & 40+ APIs): Architected full-stack backend using Django & DRF, structuring 36 relational tables and 40+ REST API endpoints with query optimization via select_related and prefetch_related.
  • Recruiter Analytics Dashboard & Middleware: Engineered dynamic Recruiter Analytics Dashboard using Chart.js & custom Django middleware for real-time visitor IP tracking, session monitoring, and interaction metrics.
  • Glassmorphism UI, Dark/Light Mode & PWA Caching: Designed responsive glassmorphism UI with Bootstrap 5, CSS variables (Dark/Light mode switcher), and Progressive Web App (PWA) offline service worker caching.
  • Docker Containerization & WhiteNoise Pipeline: Streamlined containerized deployment via Docker & Docker Compose, configured Render CI/CD build pipelines, and integrated automated static asset compression via WhiteNoise.
Platform Engineering Components
REST API & ORM Engine

Over 40 REST API endpoints delivering serialized data for projects, skills, certificates, and inquiries. Multi-table queries optimized to run sub-50ms with database indexing.

Analytics Middleware

Custom Django request middleware intercepting inbound recruiter visits, capturing geolocation, referring domains, session duration, and resume download tracking.

Docker & Render CI/CD

Containerized microservices using Dockerfile & docker-compose. Automatic deployments trigger from GitHub commits to Render with zero-downtime health checks.

WhiteNoise & PWA Offline

High-efficiency WhiteNoise Gzip and Brotli static compression with cache-control headers, coupled with Service Worker caching for instant offline accessibility.

Enterprise Software Engineer Portfolio & Analytics

Database-driven portfolio platform featuring dark/light modes, recruiter analytics, REST APIs, and PWA.

Project Overview & Architecture

A state-of-the-art production personal portfolio built with Django, DRF, MySQL, and Bootstrap 5. Includes an interactive Recruiter Analytics Dashboard, PWA support, GitHub API stats integration, visitor IP tracking middleware, verified certificate modals, and downloadable resume tracker.

Key Features & Technical Scope

• Recruiter & Admin Analytics Dashboard with Chart.js • Dark/Light Glassmorphic theme switcher with CSS variables • Django REST Framework APIs for all resources • Visitor tracking middleware & contact email auto-responder • Progressive Web App (PWA) with offline caching support

SPCart – E-Commerce Web Application

Full-featured online shopping platform with dynamic product catalog, multi-category filtering, persistent shopping cart, customer checkout, and secure user authentication.

Project Overview & Architecture

SPCart is a production-ready, full-stack E-Commerce web application developed with Python, Django, MySQL, and Bootstrap 5, deployed live on PythonAnywhere. The application implements a complete end-to-end shopping workflow: product catalog with instant search, category filtering (Electronics, Mobiles, Audio, Gaming, Wearables), session-based cart management, customer checkout, and a secure Django Admin portal for product and order management.

Key Features & Technical Scope
  • Dynamic Product Catalog: Multi-category product display with instant search and filter mechanisms.
  • Interactive Shopping Cart: Session-backed cart management with item quantity adjustment and total price calculation.
  • Customer Authentication: Secure Django auth for customer registration, login, logout, and order histories.
  • Admin Inventory Control: Comprehensive backend dashboard for managing products, categories, stock, and orders.
  • Live Cloud Deployment: Hosted and active in production on pythonanywhere.com.
Database Architecture & Data Models
  • Category Model: Slugified URLs, hierarchical categorization for Mobiles, Electronics, Audio, Wearables.
  • Product Model: SKU, pricing, discount calculation, image storage, stock availability.
  • Cart & CartItem Models: Session/User linked cart line items with real-time subtotal computation.
  • Order & OrderItem Models: Transaction tracking with shipping address, order status, and timestamps.
